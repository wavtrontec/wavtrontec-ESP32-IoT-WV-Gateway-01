The integrated RS485 and RS232 interfaces enable communication with a wide range of industrial devices such as PLCs, energy meters, sensors, controllers, weighing systems and other serial equipment.
With a 24V DC input, the gateway can be conveniently powered from standard industrial control-panel power supplies. Its combination of ESP32 processing, wireless connectivity and industrial serial interfaces makes it suitable for machine monitoring, data collection, remote diagnostics and custom IoT gateway development.

Key Features
ESP32-based industrial IoT gateway
Built-in Wi-Fi and Bluetooth connectivity
External antenna support for improved wireless communication
RS485 communication interface
RS232 communication interface
24V DC input supply
Suitable for industrial control panels

Ideal for remote monitoring and IoT applications
